# DevOps Monitoring Stack

Monitoring and observability project using Prometheus and Grafana.

## Overview
This project demonstrates how system and application metrics can be monitored using modern DevOps observability tools.

## Tech Stack
- Prometheus
- Grafana
- Docker

## Features
- Metrics collection
- Dashboard visualization
- Container monitoring

## Goals
- Understand observability concepts
- Build monitoring dashboards
- Learn production monitoring practices

## Future Improvements
- Add alert manager
- Add Kubernetes monitoring
- Add log aggregation
